# Три дара судьбы

Небольшой мобильный квест в эстетике восточной визуальной новеллы.

## Публикация на GitHub Pages

1. Создайте новый GitHub-репозиторий.
2. Загрузите в корень репозитория все файлы и папку `icons`.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
5. Откройте опубликованный адрес на iPhone через Safari.

## Установка на iPhone

1. Откройте сайт именно в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».
4. Включите «Открывать как веб-приложение», если такой переключатель отображается.
5. Нажмите «Добавить».

## Где менять текст

В `script.js` найдите массив `chapters`. Там можно менять заголовки, загадки, подсказки и текст после нахождения каждого подарка.

Финальное поздравление находится в функции `renderFinal()`.

## Важно перед квестом

- Откройте сайт заранее на телефоне и проверьте все три этапа.
- Прогресс сохраняется в `localStorage`. Для повторного теста очистите данные сайта или выполните в консоли: `localStorage.removeItem("three-gifts-progress")`.
- Сервис-воркер регистрируется после публикации по HTTPS.
- Внешний шрифт загружается из Google Fonts; при отсутствии интернета используются системные запасные шрифты.
